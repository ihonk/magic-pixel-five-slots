# 魔法像素 · 五槽实验场

一款面向手机浏览器的原创 Three.js 益智游戏原型。无需安装或构建，直接打开 `index.html` 即可运行。

在线试玩：https://ihonk.github.io/magic-pixel-five-slots/

## 玩法

- 从四支队列中选择一名队首巫师，巫师会进入第一个空的固定栏位；场上共有五个栏位。
- 巫师自动攻击与自己同色、且从某一列底部露出的像素块。下方像素会遮挡上方颜色。
- 命中后，同色像素会沿上、下、左、右连锁消除；斜向相邻不算连通。
- 巫师身上的数字表示剩余施法次数。次数耗尽后会离开栏位；暂时没有目标的巫师会继续占据栏位。
- 清空画板即可过关。若五个栏位全部占满且无人可以攻击，或队列耗尽后仍有像素，则需要重新安排派遣顺序。

原型包含三个原创演示关卡。画面以带倒角的彩色立体像素和紫色魔法界面呈现；施法时，细柔光带连接巫师与目标，命中处泛起暖色柔光，像素沿连通区域快速退去并留下柔光微粒，可行动的栏位也会高亮提示。界面针对竖屏触控布局进行了适配。

## 运行方式

这是一个无构建步骤的静态网页项目。可直接打开 `index.html`，也可以通过任意静态文件服务器运行。

主要文件：

- `index.html`：页面结构、界面样式与规则说明
- `game.js`：关卡数据、消除规则、Three.js 场景与动画
- `three.module.js`、`three.core.js`：本地 Three.js 运行库
