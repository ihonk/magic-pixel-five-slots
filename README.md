# 魔法像素 · 五槽实验场

一款面向手机浏览器的 Three.js 益智游戏原型，提供网页版本和可离线直接打开的单文件版本。

在线试玩：https://ihonk.github.io/magic-pixel-five-slots/

## 玩法与表现

- 36 × 36 像素棋盘，共有三个演示关卡。
- 点击地面三支纵列中的巫师，将其送入五个固定槽位。巫师会从全棋盘选择与自己同色、且从某一列底部露出的最大连通块进行攻击。
- 同色像素按上、下、左、右连通；命中后由 shader 呈现沿连通区域推进的引信式消除。
- 巫师保留有限施法次数。槽位受阻时可通过复活机制继续，清空棋盘后进入通关结算与下一关。
- 画面包含倒角像素、巫师队列与过场效果；音效由 Web Audio API 即时合成，不依赖外部音频文件。

当前版本还处理了计时器与视觉残留清理、GPU 资源释放、手机屏幕裁切，以及重开按钮的状态恢复。

## 运行与构建

网页版本由以下文件组成：

- `index.html`：页面结构、界面样式与交互容器
- `game.js`：关卡、玩法、渲染、动画与合成音效
- `vendor/three.r147.min.js`：本地 Three.js r147 运行库

通过静态文件服务器打开 `index.html` 即可运行在线结构。若需要不依赖服务器的单文件版本，执行：

```sh
python3 tools/build-standalone.py
```

脚本会将页面、游戏逻辑和本地 Three.js 运行库内联，生成 `magic_fever_standalone.html`；该文件可离线直接打开。
